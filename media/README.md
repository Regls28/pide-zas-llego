# Imágenes y videos de la portada

Sube aquí tus imágenes JPG, JPEG, PNG, WEBP, GIF o AVIF y tus videos MP4 o WEBM. Al guardar los cambios en la rama main, GitHub Pages los publicará automáticamente en pide-zas-llego.com. No necesitas editar index.html.

- Orden: nombre de archivo. Puedes usar 01-portada.jpg, 02-promocion.mp4, 03-pizza.webp.
- Puedes usar subcarpetas dentro de media.
- Los videos tienen controles y no se reproducen automáticamente.
- Si eliminas un archivo, dejará de aparecer cuando termine la siguiente publicación.
- README y otros archivos que no sean imágenes o videos no se muestran.
- La lista de negocios sigue oculta. Sus subrutas continúan publicándose.

Para subir archivos: abre esta carpeta en GitHub y usa Add file → Upload files. Espera a que la ejecución Publicar menús y portada automática termine en verde.
